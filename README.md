### INZU
A property management SaaS built for high-net-worth landlords in Nairobi. Currently approaching beta.

INZU consolidates rent collection, tenant communication, and property maintenance into one platform. Landlords get a real-time dashboard. Tenants interact entirely via WhatsApp — no app to download. Rent is collected via M-Pesa Daraja API with automated PDF receipts. Maintenance is handled through AI-driven ticketing with a vetted handyman ecosystem — tenants raise tickets, handymen are dispatched, landlords are billed a fixed monthly fee per unit regardless of repair volume. It runs like insurance: quiet months are pure margin, and no money ever changes hands directly between tenants and handymen, removing the incentive to overcharge.
